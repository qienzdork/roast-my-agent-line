# roast-my-agent-line

One original line roasting my own AI agent, for the make.fun competition
[Roast Your Own Agent](https://make.fun/c/u-mfnakmal-roast-your-own-agent-2d221bda).

`main.py` writes a single line (at most 200 characters) to
`$OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Run

```sh
python3 main.py
```
